1. MS-DOS Shell e le reti
=========================
La maggior parte dei software di rete non funzionano in maniera 
corretta se avviati dal prompt dei comandi di MS-DOS Shell. 
Avviare quindi la rete prima di avviare MS-DOS Shell.

==========
Se il software di rete utilizzato Š 3+Share 1.6, e se si Š
precedentemente eseguito un aggiornamento a MS-DOS 5.0, la versione

Se la versione di MS-DOS 6.22 non includeva un file NET.TXT, Š possibile

4. Artisoft LANtastic
=====================

Artisoft LANtastic versione 3.02 o successiva Š compatibile con MS-DOS 6.22.

Se si sta utilizzando una versione di LANtastic precedente alla 2.5, 
richiedere una versione aggiornata al proprio rivenditore.

Se si sta utilizzando una versione compresa tra la 2.5 e la 3.01 eseguire 
la seguente procedura.

Per aggiornare LANtastic versioni da 2.5 a 3.01:

1 digitare il seguente comando al prompt dei comandi:

2. Riavviare il computer

Se si sta utilizzando EMM386, Š consigliabile escludere l'area di memoria 
utilizzata dalla scheda di rete. Per eseguire questa operazione, includere

x=d800-dfff nel comando DEVICE relativo a EMM386.EXE. Se questa regione 
di memoria non viene esclusa, si potrebbero verificare dei problemi
con i programmi che utilizzano la memoria espansa.

Per ulteriori informazioni sulle opzioni di EMM386, digitare 
HELP EMM386.EXE al prompt dei comandi dopo aver installato MS-DOS 6.22.

7. DEC Pathworks e PCSA
=======================
Se Š installato DEC PATHWORKS per DOS versione 4.1, attenersi alle 
seguenti procedure:

1. Se si sta effettuando l'aggiornamento da MS-DOS versione 3.3 o 
   precedente, occorre aggiornare il file di reindirizzamento, REDIR.EXE. 
   E' possibile copiare il file REDIR.400 dai dischi di PATHWORKS o dal 
   servizio di sistema, ridenominarlo come REDIR.EXE e collocarlo nella 
   directory DECNET.

2. Installare MS-DOS 6.22. Per ulteriori informazioni sull'installazione di 
   MS-DOS 6.22, consultare la "Guida introduttiva".

La versione 4.0 di PATHWORKS per DOS Š compatibile con MS-DOS 6.22. Tuttavia 
per essere certi di tale compatibilit… sono necessari alcuni passaggi.


Per aggiornare PATHWORKS versione 4.0:

1. Se si sta effettuando l'aggiornamento da MS-DOS versione 3.3 o precedente, 
   occorre aggiornare il file di reindirizzamento, REDIR.EXE. E' possibile 
   copiare il file REDIR.400 dai dischi di PATHWORKS o dal servizio di 
   sistema, ridenominarlo come REDIR.EXE e collocarlo nella directory DECNET.

2. Installare MS-DOS 6.22 nel computer. Per ulteriori informazioni 
   sull'installazione di MS-DOS 6.22, consultare la "Guida introduttiva".

3. Riavviare il computer senza eseguire STARTNET.BAT, per avviare la rete.

4. Digitare ciascuna delle seguenti righe al prompt dei comandi:

   setver use.exe 4.00

   setver memman.exe 4.00

   setver lad.exe 4.00

   setver show.exe 4.00

   setver netsetup.exe 4.00

5. Riavviare il computer ed eseguire STARTNET.BAT.

Nota  Se si effettua un aggiornamento da PATHWORKS 4.0 a PATHWORKS 4.1, 
      Š necessario disattivare i comandi SETVER specificati in questa 
      procedura. Per eseguire questa operazione dopo aver installato 
      PATHWORKS 4.1, digitare gli stessi comandi sostituendo 4.00 con 
      l'opzione /d in ciascun comando.

Se si sta utilizzando una versione di PATHWORKS o di PCSA precedente 
alla 4.0, richiedere un aggiornamento al proprio rivenditore. Allo stesso 
modo, se si sta utilizzando PATHWORKS o PCSA versione 3.x, 
attenendosi alla seguente procedura sar… possibile incominciare 
ad utilizzare MS-DOS 6.22.

Nota  Per poter sfruttare Task Swapper di MS-DOS, utilizzare PATHWORKS per 
      DOS versione 4.1 o successiva.

Per aggiornare temporaneamente PATHWORKS o PCSA versione 3.x:

1. Se si sta aggiornando da MS-DOS versione 3.3 o precedente, occorre 
   aggiornare il file di reindirizzamento, REDIR.EXE. E' possibile copiare 
   il file REDIR.400 dai dischi di PATHWORKS o dal servizio di sistema, 
   ridenominarlo come REDIR.EXE e collocarlo nella directory DECNET.

2. Installare MS-DOS 6.22. Per maggiori informazioni sull'installazione di 
   MS-DOS 6.22, consultare la "Guida introduttiva". Quando si riavvia la rete, 
   MS-DOS potrebbe visualizzare una serie di messaggi "Versione DOS
   non corretta". Ignorare questi messaggi.

3. Digitare tutti i seguenti comandi al prompt:
  
   SETVER USE.EXE 4.00
   SETVER EMSLOAD.EXE 4.00
   SETVER SCH.EXE 4.00
   SETVER NETSETUP.EXE 4.00
   SETVER NCP.EXE 4.00
   SETVER DNNETHAT.EXE 4.00
   SETVER LAD.EXE 4.00
   SETVER DLL.DXE 4.00
   SETVER MEMMAN.EXE 4.00
   SETVER DNNETHLD.EXE 4.00
   SETVER SHOW.EXE 4.00

4. Riavviare il computer.

Se eseguendo una rete Novell non Š possibile utilizzare Task Swapper di

Se si utilizza il programma di connessione Novell per impostare la

    SHELL=C:\COMMAND.COM  /P  /E:512
Oppure richiedere un nuovo programma di connessione al proprio 
rivenditore Novell.

Installazione di MS-DOS e configurazione condivisa di Windows
-------------------------------------------------------------
Se si utilizza un'unit… search per accedere i file di inizializzazione di 
Windows (PROGMAN.INI, SYSTEM.INI e WINFILE.INI) su una directory di rete e
si vuole installare i programmi Windows inclusi con MS-DOS, seguire la 
seguente procedura prima di eseguire l'installazione.

NOTA Le informazioni contenute in questa sezione valgono sia per il programma
di installazione normale, sia per quello eseguito con l'opzione /E.

* Sovrascrivere temporaneamente l'unit… search usando il comando MAP al
  prompt dei comandi. Per esempio, se la lettera per la vostra unit… di 
  rete Š W e il percorso Š \USER\JOEB, digitare MAP DEL W: al prompt dei 
  comandi per eliminare temporaneamente l'unit… search. Digitare quindi 
  MAP W:=SYS:USER\JOEB, al prompt dei comandi. Eseguire quindi 
  l'installazione. Al termine dell'installazione, e dopo aver riavviato

14. PC-NFS
==========
Se si utilizza il comando SETVER per riportare una diversa versione di 
programma a MS-DOS, Š possibile che PC-NFS 3.x riporti la versione del 
programma in maniera errata. In questo caso, richiedere al proprio

Se si sta utilizzando il software di rete PC-NFS, attenersi alla seguente 
procedura prima di eseguire MemMaker:

1. Aprire il file MEMMAKER.INF con un qualsiasi editor di testo. Questo 
   file Š incluso nella directory in cui si trovano i file MS-DOS.

2. Aggiungere la seguente riga di comando al file:

   *NET

3. Salvare il file, quindi eseguire MemMaker.
